# Ловец звёзд

Небольшая браузерная игра без зависимостей: поймай как можно больше звёзд за 30 секунд.

## Запуск

Откройте `index.html` в браузере. Игра работает на компьютере и телефоне.

## Возможности

- счёт и таймер;
- локальное сохранение рекорда;
- звуковые эффекты без аудиофайлов;
- адаптивная вёрстка;
- поддержка режима уменьшенной анимации.
