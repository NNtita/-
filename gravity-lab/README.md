# Gravity Lab — Последний вектор

Браузерная 3D-головоломка от первого лица. Семь глав, разные ловушки и законченная история.
После аварии на станции «Вектор» последний инженер восстанавливает системы и ищет путь
к эвакуации. Бортовой ИИ ЛИРА сопровождает его короткими сообщениями.

## Играть

Самый простой способ: скачайте [Gravity-Lab.html](./Gravity-Lab.html) кнопкой
**Download raw file** на странице файла в GitHub и откройте его в современном браузере.
Можно также скачать весь репозиторий через **Code → Download ZIP**, распаковать архив
и открыть `gravity-lab/Gravity-Lab.html`. Установка пакетов и интернет для игры не нужны.
Браузер должен поддерживать WebGL 2. В самом просмотрщике кода GitHub игра не запускается.

Выберите одну из семи комнат и начните эксперимент.
Наведитесь на стену или потолок и нажмите левую кнопку мыши: эта поверхность станет полом.
После решения задачи комнаты верните гравитацию на исходный пол и войдите в EXIT.

Управление: WASD / стрелки — движение, мышь — обзор, ЛКМ / E — смена гравитации,
пробел — прыжок, Shift — ускорение, R — сбросить текущую комнату, H — подсказка, Esc — пауза.
Если браузер не позволяет захватить указатель, обзор работает при удержании правой кнопки мыши.
На сенсорном экране: стик слева, обзор свайпом по сцене, кнопки справа.
Звук включается отдельной кнопкой.

## Что готово

- Настоящая 3D-сцена с освещением и тенями, шесть направлений гравитации.
- Движение, прыжок и столкновения; плавная смена ориентации камеры.
- Камера 01 «Перспектива»: освоение гравитации, три энергоячейки на разных поверхностях.
- Камера 02 «Масса»: доставка куба по магнитной направляющей на платформу A, снятие защиты ключа.
- Камера 03 «Цепная реакция»: платформа A освобождает куб B; после активации B открывается ключ.
- Камера 04 «Импульс»: два шлюза на всю высоту помещения с отдельными циклами включения.
- Камера 05 «Сжатие»: два движущихся пресса и модули охлаждения между ними.
- Камера 06 «Сканирование»: перемещающиеся по высоте лучи и электрический пол.
- Камера 07 «Последний вектор»: последовательные контуры, гравитационный пилон, шлюз, пресс и ядро ЛИРЫ.
- Финал: отдельная 3D-сцена эвакуации и завершение истории. Пробел позволяет пропустить сцену.
- Лазерные поля, которые нужно обходить по стенам или потолку. При ошибке решённые механизмы сохраняются.
- Выбор любой из семи глав, последовательные переходы, три ступени подсказок для каждой комнаты.
- Завершённые комнаты и последняя выбранная комната сохраняются на этом устройстве.
- Пауза при потере фокуса и интерфейс для сенсорного экрана.

Кубы в учебной комнате свободно падают. В комнатах 02 и 03 они закреплены на магнитных
направляющих и скользят только вдоль их оси под действием гравитации. Приёмная платформа
автоматически фиксирует доставленный куб, после чего гравитацию можно менять дальше.

## Проверка

Проверено в локальном Microsoft Edge: отсутствие ошибок загрузки, контакт с каждой из
шести поверхностей, сбор ячеек, победа, перезапуск и пауза. Проверены зависимость A → B,
невозможность собрать защищённый ключ, возврат после ловушек и сброс только текущей камеры.
Проверены активные и безопасные интервалы лазеров, открытый и закрытый пресс,
движущийся луч, электрический пол и остановка циклов на паузе. Собранные модули
и зафиксированные кубы сохраняются после возврата.
Новые маршруты пройдены клавиатурным движением и переключениями гравитации без переноса персонажа.
Проверены финальная сцена, переход к титру и повторный запуск истории.
Проверена вёрстка 1440×900 и 390×844. Настоящий телефон и другие видеокарты не проверялись.
WebMCP активируется при поддержке браузером; регистрация в поддерживающем браузере
не проверена, так как в тестовом Edge этого API нет.

## Проект

`Gravity-Lab.html` — готовая автономная версия для запуска двойным щелчком;
`dist/index.html` — интерфейс; `dist/style.css` — оформление;
`dist/game.js` — сцена, игровая логика и физика;
`dist/vendor/three.module.js` — Three.js r170, лицензия MIT рядом.
Внешние загрузки во время игры не нужны. Установка пакетов и сборка не требуются.
Для локальной разработки каталог `dist` нужно открыть через любой локальный HTTP-сервер,
а не через адрес file://.

Например, если установлен Python, из папки `gravity-lab` выполните:

```sh
python -m http.server 8000 --directory dist --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8000`. Для публикации на статическом хостинге
используйте содержимое `dist`. Автономная версия — отдельная готовая копия:
изменения в `dist` не переносятся в неё автоматически.

Three.js распространяется по лицензии MIT, полный текст —
[dist/vendor/THREE-LICENSE.txt](./dist/vendor/THREE-LICENSE.txt).
Игра «Ловец звёзд» в корне репозитория сохранена отдельно.
